# Suite3 — 第 20 步：一次性创建完整项目骨架

## 测试场景

在空 workspace 中一次性创建多个目录和文件。

## 提示词

```
为 MyVibeOS 创建基础项目结构：
创建 kernel/ 目录，创建 kernel/kernel.h（包含 #pragma once 和 void kernel_main(void); 声明），
创建 kernel/kernel_main.c（包含 #include "kernel.h" 和空的 kernel_main 函数），
创建 Makefile（包含 all、run、clean 目标），
创建 README.md（写一句项目简介）。
```
