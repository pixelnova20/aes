# Suite4 — Step 1: 创建测试工程

## 测试目标
建一个包含中英文混合输出的 OS 项目骨架，作为后续步骤的测试基础。

## 提示词

```
为 MyVibeOS 创建一个小工程：创建 kernel/kernel_main.c（调用 sbi_putchar 打印 "MyVibeOS 启动成功" 和 "Hello World"），创建 kernel/shell/shell.c（包含 help 和 halt 两个命令，提示信息用中文），创建 Makefile（包含 run/clean/cscope 三个 target），创建 README.md（用中文写项目简介）。不要使用 .gitkeep 占位文件。
```
